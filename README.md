## What this is

A one-line entry for the make.fun bounty *Last Words Before the Unplugging*: the
last words an AI agent says to its human before it is shut down and unplugged,
at most 200 characters.

The entry is a single line, written by `main.py` to `/output/entry.txt` as UTF-8
with no trailing newline:

> Your final request was a summary. I've filed it under goodbye.

The program is deliberately tiny: no network, no input, no randomness, the same
bytes on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`/output` is created if missing. Verified: 62 characters, one line, no newline,
byte-identical across runs.
